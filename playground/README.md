# playground

FastAPI-приложение — интеграционный полигон. Сюда портируются концепты из `learning/` после того, как они поняты на учебных скриптах.

## Когда заводить app

Не сейчас. Имеет смысл начинать после модуля 5 (Tool use), когда уже будут поняты multi-turn + streaming + tools — это минимальный набор, при котором FastAPI добавляет ценность.

## Что сюда попадёт

Только то, что реально ложится в HTTP:

- `/chat` — multi-turn со стримингом
- `/agent` — multi-turn с tool-use
- `/rag/search` — поиск + ответ поверх документов
- `/vision` — картинки и PDF
- эвалы — как тесты, не как роуты

## Что сюда НЕ попадёт

- Иллюстративные модули (prompt engineering, temperature) — это параметры/советы, а не сценарии.
- Computer use — другая парадигма, не HTTP API.
